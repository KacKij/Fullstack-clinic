This is your new *obsidian vault*.

Obsidian is a notebook app you can get at https://obsidian.md/

It works line a notepad, and creates .md files in a folder structure with funny little syntax things that connect notes, screenshots, graphs and more.

This doc is based on it so if you want to see the documentation i recommend you install it and select the Fullstack-clinic/Documentation folder as a root for a vault.

Whenever you are ready, go to the [[Fullstack-clinic]]
